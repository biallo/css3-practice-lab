# CSS3 Practice Lab

一个 CSS3 重要知识点的课程练习项目。

## 在线预览

[https://biallo.github.io/css3-practice-lab/](https://biallo.github.io/css3-practice-lab/)

## 运行

```bash
npm install
npm run dev
```

## 内容

- CSS 选择器与优先级
- Flexbox 布局
- Grid 网格布局
- 背景与渐变
- 阴影与边框
- Transition 与 Animation
- 媒体查询与响应式布局
- 自定义属性与变量
- 滤镜与混合模式
- 排版与文本样式
